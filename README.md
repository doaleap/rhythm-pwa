# 🎵 音乐鼓点闪动播放器

> 一个会“听音乐”的网页播放器。背景颜色随音乐能量流动，闪光灯跟随鼓点BPM跳动。

这是一个用 **Cursor + Vibe Coding** 实现的音乐可视化实验项目。它调用 Spotify API，让你可以搜索并试听任何歌曲的30秒预览，同时通过 Web Audio API 实时分析音频特征，让页面“活”起来。

## ✨ 核心亮点

| 功能 | 描述 |
|------|------|
| 🎤 **Spotify 搜索** | 搜索你喜欢的歌曲，播放30秒试听片段 |
| 🎨 **能量变色** | 背景色根据音乐能量从深蓝渐变成亮红、亮紫 |
| 💡 **BPM 闪光** | 音乐鼓点越强，背景“闪光”越剧烈，与心跳/BPM同步 |
